ROOT LEVEL PAGES:
┌─────────────────────────────────────────────────────────────────────────┐
│ index.html               → Homepage / Main Dashboard                      │
│ login.html              → User Sign-In Page                              │
│ register.html           → User Registration Page                         │
│ profile.html            → User Profile (Auth Required)                   │
│ admin.html              → Admin Management Dashboard                     │
│ gallery.html            → Old Gallery (Static)                           │
│ gallery_new.html        → New Gallery (Dynamic, Firebase)                │
│ tech-titans.html        → Tech Titans Club Page                          │
└─────────────────────────────────────────────────────────────────────────┘

ASSET FILES:
├── styles.css            → Main stylesheet
├── main.js               → Main JavaScript file
├── gallery_new.css       → Gallery styling
├── gallery_new.js        → Gallery JavaScript
└── README.md             → Project documentation

FIREBASE CONNECTED:
├── index.html            (Events, News, Winners, Registrations)
├── profile.html          (User Data, Activity, Feedback)
├── admin.html            (All CRUD Operations)
├── gallery_new.html      (Image Uploads)
├── tech-titans.html      (Events, Feedback, Suggestions)
└── login.html / register.html (Authentication)

═══════════════════════════════════════════════════════════════════════════
                    FIREBASE COLLECTIONS STRUCTURE
═══════════════════════════════════════════════════════════════════════════

Firestore Database:
├── events/
│   ├── [eventId]
│   │   ├─ title
│   │   ├─ description
│   │   ├─ date
│   │   ├─ time
│   │   ├─ club
│   │   ├─ eventType (Workshop/Seminar/Event/Hackathon)
│   │   ├─ venue
│   │   ├─ fees
│   │   └─ participants[]
│   └── [eventId2]...
│
├── registrations/
│   ├── [regId]
│   │   ├─ userId
│   │   ├─ userName
│   │   ├─ userEmail
│   │   ├─ eventId
│   │   ├─ eventName
│   │   ├─ eventDate
│   │   ├─ club
│   │   ├─ registeredAt
│   │   ├─ attendance (Present/Absent)
│   │   └─ tokenId
│   └── [regId2]...
│
├── feedback/
│   ├── [feedbackId]
│   │   ├─ userId
│   │   ├─ userName
│   │   ├─ userEmail
│   │   ├─ club
│   │   ├─ eventName
│   │   ├─ feedback
│   │   ├─ submittedAt
│   │   ├─ status (new/replied)
│   │   └─ reply
│   └── [feedbackId2]...
│
├── suggestions/
│   ├── [suggestionId]
│   │   ├─ userId
│   │   ├─ userName
│   │   ├─ userEmail
│   │   ├─ club
│   │   ├─ suggestionType
│   │   ├─ suggestion
│   │   ├─ submittedAt
│   │   ├─ status (new/replied)
│   │   └─ reply
│   └── [suggestionId2]...
│
├── news/
│   ├── [newsId]
│   │   ├─ title
│   │   ├─ content
│   │   ├─ category (Announcement/Achievement/Update)
│   │   └─ date
│   └── [newsId2]...
│
├── gallery/
│   ├── [photoId]
│   │   ├─ imageUrl
│   │   ├─ caption
│   │   ├─ category
│   │   └─ uploadedAt
│   └── [photoId2]...
│
└── winners/
    ├── [winnerId]
    │   ├─ name
    │   ├─ event
    │   ├─ position (1st/2nd/3rd/consolation/special)
    │   ├─ description
    │   └─ createdAt
    └── [winnerId2]...
